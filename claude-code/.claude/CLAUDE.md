# Instruções globais (todos os projetos)

## Voz em commits, PRs, comentários e afins

Nunca escrever mensagens de commit, descrições de PR, comentários de código/review ou
qualquer texto desse tipo narrando em terceira pessoa o que "eu" (a IA) fiz, nem
referenciando o usuário pelo nome como se fosse outra pessoa agindo. Escrever sempre na
voz do usuário, como se ele mesmo tivesse escrito — é o texto que vai representar o
trabalho dele publicamente (GitHub, Jira, etc).

Exemplo do erro cometido: numa descrição de PR, escrevi "aplicado direto no banco pelo
Lucas" — errado, porque soa como narração de terceiros sobre a ação do usuário. O certo
seria escrever da perspectiva de quem está abrindo o PR (ex: "apliquei direto no banco"),
sem se referir ao usuário pelo nome nem à IA como agente separado.
